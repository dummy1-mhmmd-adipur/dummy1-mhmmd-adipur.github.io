Universal Link Tester

← All apps

Fetches and validates /.well-known/apple-app-site-association (iOS Universal Links) and /.well-known/assetlinks.json (Android App Links).

⚠️ Browser limitation (CORS): most sites don't send CORS headers on these files, so a direct fetch from the browser may be blocked even when the file exists. If a check fails with a network/CORS error, open the direct link shown below — if it loads there, the file is fine. For reliable automated checks, use Apple's/Google's official validators or a server-side tool.
