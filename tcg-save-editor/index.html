Welcome to the Save Editor!

To get started, click Load Save at the top or drag and drop your save file anywhere on the screen. Both PC (.json) and Nintendo Switch (GameData_1) save files are supported.

🖥️ PC — Where is my save file located?

Copy and paste this exact path into your Windows File Explorer address bar:

%USERPROFILE%\AppData\LocalLow\OPNeonGames\Card Shop Simulator\
Look for the file named savedGames_Release0.json
🎮 Nintendo Switch — Where is my save file located?

Use a save manager such as JKSV to back up your save from the console, then load the exported file here:

JKSV/Card Shop Simulator/<backup folder>/GameData_1
Load the file named GameData_1 (and/or GameData_0). When you export, the editor rebuilds a valid GameData_1 file — ready to restore with JKSV.
